# M0 Harness Core 작업 지침

[현재 상태](../../docs/STATUS.md)와 [M0 SDD](../../docs/specs/M0-harness-core.md)를 확인하고 명시적으로 승인된 단일 작업만 수행한다. 목표와 전체 Exit Gate는 [마스터 플랜](../../docs/MASTER_PLAN.md)을 따른다.

1. 기존 파일과 Git 상태를 읽기 전용으로 조사하고 충돌을 보존한다.
2. 승인 범위와 수용 기준을 확인하고 해당 범위만 변경한다. 범위 확장이나 중요한 미결정은 보고하고 승인을 기다린다.
3. 실제 검증을 실행하고 실패·미실행 사유와 증거를 [build-log](../build-log.md)에 기록한다. 미추적 파일도 확인한다.
4. STATUS를 실제 상태로 갱신하고 변경, 영향, 검증, 위험, Git 상태 및 다음 행동을 보고한다.
5. 사용자 승인 전 REVIEW를 유지한다. 마일스톤 완료나 다음 작업을 임의로 진행하지 않는다.

M0-001은 문서와 저장소 초기화에 한정한다. Android/Backend, CI 구현, 외부 비용, commit/push는 승인 범위 밖이다.
