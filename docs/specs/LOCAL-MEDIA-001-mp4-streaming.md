# LOCAL-MEDIA-001 — 로컬 Progressive MP4 VOD

상태: 진행 중. 기준 `580f420`; 에뮬레이터 전용 Debug 시연. 사용자가 공개 가능하다고 설명한 영상이나 원본·복사본·변환본 파일은 Git/CI에 포함하지 않는다. 화면에서 제3자 제작 크레딧이 관찰되어 공개 캡처는 권리 확인 전 보류한다. 개인 파일명과 경로는 공개하지 않는다.

기존 Spring 서버에 고정 ID 7개의 읽기 전용 HTTP 리소스를 선택적으로 추가하고 정상 Range를 지원한다. Debug Media 카드와 기존 룸을 표시 순서로 연결한다. 기존 HLS와 채팅 경로 및 Release cleartext 정책을 보존한다. 서버 부재 화면/자동 fallback과 비정상 Range 상세 검증은 NOT_RUN_DEFERRED. 실기기는 사용하지 않는다.

검증 게이트: 원본 해시와 복사본, 7개 HTTP 및 정상 206, 7개 에뮬레이터 첫 프레임/오디오 트랙, 대표 재생·오디오·탐색·해제, 기존 HLS/채팅 회귀. 실행한 것만 PASS로 기록한다.

## 실제 구현 계약
- Debug Media에 일곱 영상을 표시한다. 첫 세 영상은 기존 룸 순서대로 채팅 화면을 사용하고 나머지는 Replay 상세를 사용한다. 기존 HLS 진입은 유지한다. 영상에 Local VOD·prerecorded를 표시한다.
- 지정된 디렉터리의 고정 파일명만 `Resource`로 읽는다. loopback 포트 및 읽기 전용 바인드는 로컬 실행자의 필수 조건이다. 인증·운영 공개는 범위 밖이다.
- 정상 206과 미등록/미설정/경로 순회 거부는 필수다. 비정상 Range 상세와 서버 부재 화면은 후속으로 남긴다.

## USB 연결 실기기 실행 (2026-11-06)
사용자가 기존 앱 덮어쓰기를 요청했다. Debug 재생 주소는 에뮬레이터에서는 `10.0.2.2`, 실기기에서는 `127.0.0.1`을 사용한다. 실기기는 `adb reverse tcp:18765 tcp:18765`로 호스트 loopback 서버에 연결하며 LAN 공개는 필요하지 않다. USB 연결이 끊기거나 기기를 재시작하면 reverse 설정을 다시 확인해야 한다. Debug 빌드/lint 및 기존 앱 위 설치·실행 PASS, USB 경유 영상 HEAD 200 PASS. 실기기 화면 재생 및 오디오 청취는 NOT_RUN.

## 일반 영상과 벤치마크 구분 (2026-11-06)
Debug에서 홈 추천·룸·Replay 및 Media의 일반 카드는 로컬 MP4로 연결한다. 기존 룸 순서대로 영상 ID를 선택하고 목록 길이가 영상 수를 넘으면 순환한다. 합성 HLS는 벤치마크용임을 카드에 표기하고 홈 룸 목록 및 Replay, Media 필터 목록의 마지막에 배치한다. 실제 영상이 없는 기본 Release의 로컬 HTTP·cleartext 정책은 변경하지 않는다.
- Debug 빌드·lint PASS. 전용 API 36에서 홈·Media 첫 일반 카드의 로컬 영상 첫 프레임, 벤치마크 HLS와 기존 탐색·입력 회귀 포함 19/19 PASS. 실기기 및 전체 실제 서버 회귀 NOT_RUN.
