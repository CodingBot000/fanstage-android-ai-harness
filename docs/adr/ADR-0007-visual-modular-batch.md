# ADR-0007 — 시각 개선 후 기능별 모듈화

상태: 제안·진행 중 (2026-11-05). 사용자 요청에 따른 v0.1/M9와 별도의 UX-007~011 및 ARCH-001~003 작업이다.

## 방향
기존 LIVE/Chat 및 서버 계약을 보존하면서 먼저 화면·자산을 개선하고 실제 화면 증거를 확보한다. 이후 순수 모델과 Repository 계약·Fake 구현·기능 화면을 책임별 모듈로 단계적으로 분리한다. App은 navigation과 의존성 조립을 담당한다. 구체적 의존 방향과 실제 이동 결과는 ARCH SDD에 기록한다. 사용자가 승인한 전체 회귀의 최종 통합 시점과 ADR-0005의 관련 P0/P1 차단 조건을 함께 적용한다.

## 대안 및 한계
시각 개선과 모듈 이동을 동시에 수행하면 회귀 원인을 분리하기 어렵다. 기존 모든 기능을 app에 유지하면 경계가 강제되지 않는다. 단계별 이동은 중간 빌드 및 문서 갱신 비용이 있으나 상태·자원 수명 회귀를 좁혀 확인할 수 있다. 신규 유료 인프라나 자격 증명은 포함하지 않는다.
