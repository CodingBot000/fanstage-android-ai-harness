# ADR-0009: 테스트 전용 장애 주입

상태: 진행 중. M5 전체 Gate를 통과했다는 의미는 아니다.

실제 서버 코드는 변경하지 않고 테스트 전용 loopback TCP 프록시가 최초 ACK WebSocket 프레임을 버린다. 독립 Compose 프로젝트의 합성 PostgreSQL 데이터를 조회해 커밋과 네트워크 전달을 구분한다. 같은 ID 재전송 후 다른 구독자에게 두 번째 방송이 없는지도 확인한다. 첫 ACK를 보낸 뒤 실제 전송 계층에서 프레임을 버리는 시나리오는 DB commit 실패 시나리오와 별도다.

Android는 실제 WebSocket과 결정적 Fake를 병행하고 HLS 장애는 에뮬레이터 내부 loopback HTTP fixture에서 주입한다. 테스트에서만 404, 지연 및 끊김을 재현하며 운영 서버의 조작 가능한 fault API나 새로운 서비스는 추가하지 않는다. 본 테스트가 검증하지 않은 실제 장치 네트워크 전환·전 과정 통합·장기 리소스 계측은 [M5 SDD](../specs/M5-fault-recovery.md)에 NOT_RUN으로 남긴다.

CI는 기존 분리 Compose 프로젝트를 재사용하며 실행이 끝나면 자신이 생성한 합성 데이터만 제거한다. 로컬 개발 DB와 기타 볼륨을 초기화하지 않는다. 큐·시간 관련 한도 검사는 유한한 회귀 시험이지 성능 목표 또는 M6 벤치마크가 아니다.
