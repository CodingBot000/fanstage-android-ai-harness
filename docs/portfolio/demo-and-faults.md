# 시연과 장애·복구 검증

## 기본 화면 시연

[무음 시연 영상 (MP4, 약 23초)](media/offline-demo.mp4)은 격리된 API 36 에뮬레이터에서 로컬 검증 전용 rcLocal APK를 캡처한 것입니다. 목록, 상세, 합성 VOD 일시정지·재개 및 Fake 채팅 전송·확인을 보여 줍니다. 원본 화면의 상태 표시줄과 Google 키보드가 나온 구간을 제외하고 크기를 조정했습니다. 네트워크 단절·복구는 이 영상에 포함되지 않습니다.

앱은 실행 후 가상의 방 목록을 표시합니다. 방을 선택하면 앱에 포함된 무음 합성 VOD가 재생되고, 일시정지·재개할 수 있습니다. 아래로 스크롤해 Fake 채팅을 보내면 Pending 이후 확인 상태를 볼 수 있습니다. 뒤로 가면 목록으로 돌아갑니다. 실제 방송이나 원격 LIVE는 사용하지 않습니다.

로컬 빌드와 실행은 [빠른 시작](../../README.md#빠른-시작)을 따릅니다. 영상은 FFmpeg `testsrc2`로 생성한 fixture이며 생성 명령은 [M2 SDD](../specs/M2-hls-player.md)에 있습니다.

## 별도로 확인한 장애와 복구

기본 Fake 데모 화면에서 물리 네트워크를 끊는 것은 실제 서버 복구 시연이 아닙니다. 실제 서버 연동과 장애 주입은 별도의 테스트에서 확인했습니다.

1. ACK와 발신자 echo를 테스트 프록시에서 유실시켜 Pending이 불확실하게 유지되는지 확인하고, 같은 메시지 ID로 재전송하여 중복 저장을 검사합니다.
2. 소켓 취소와 재접속, HTTP snapshot으로 누락 이벤트를 복구합니다. 테스트 서버의 10초 단절과 Android의 10초 backoff는 기록된 범위에서 각각 확인했습니다.
3. 영상 fixture의 segment 오류를 주입해 오류와 재시도를 확인합니다. Player 오류와 채팅 동작의 독립성도 별도로 확인합니다.

세부 PASS/부분 PASS/NOT_RUN은 [M5 SDD](../specs/M5-fault-recovery.md)를 확인하세요. 독립적인 서버를 준비하려면 [서버 README](../../backend/chat-server/README.md)를 사용합니다. 운영 자격값이나 실제 사용자 데이터는 사용하지 마세요.

## 재현과 공개 범위

기본 데모는 소스에서 빌드합니다. 공개 APK와 원본 실기기 trace는 제공하지 않습니다. 원격 LIVE 첫 프레임, 실제 LMK, 실제 네트워크 부하·전환 및 장시간 메모리 측정은 NOT_RUN입니다. 포트폴리오 수치는 [M6 실험 기록](../reviews/M6-002-ab-experiments.md)과 그 조건을 함께 읽어야 합니다.
